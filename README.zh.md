# SideDesk

[English](README.md) · 中文

![待回复、草稿、有人接话，以及一条监控](docs/sidedesk-usage.gif)

SideDesk 是一个装在本机上的跟进台，给在公开社区里回复别人的人用。它由三部分组成：本机上的一个小 API、一份 SQLite 数据库，以及 Chrome 窗口右侧的侧边栏。你正在看的网页还在左边。

你在 Reddit、哔哩哔哩、YouTube、V2EX、知乎这类地方回复时，用它把两件事放在一处：

1. **哪些新帖值得回。** 一条关键词监控、你贴进来的链接，或者左边已经打开的页面，都会变成一条线索。待办里留着你还没回的。
2. **你回过之后下面发生了什么。** 你把已经发出的评论链接贴回来。SideDesk 记下它，之后再看这条评论下面有没有人接话、分数有没有变、评论还在不在。

回复由你自己写、自己发到原站。SideDesk 保管队列、草稿和评论链接。你把草稿复制出来，贴到原页面，在那里发出去。

这里的一个**项目**就是你正在讲的那件事。第一次启动会建一个空项目，名字是「默认」。名称、背景和监控都由你填。背景是给写稿模型看的说明：这是什么、能做什么、哪些话不能说、语气怎样。这个台子是在推广 ThinkNote 时做出来的，台子本身不预设任何产品。

## 一天里怎么用

1. 打开**项目**，写好背景。还可以存两段很短的补充说明，中文和英文各一段，留给对方追问的时候。这两段不放进第一条回复，对方问了再复制。
2. 打开**监控**，加一个关键词或一条链接。关键词会拿去搜 Reddit。链接按站点识别：帖子变成待回复的线索；你自己的评论则存下来，之后再查。左边已经打开的页面也可以直接加成线索，不必先建监控。
3. 打开侧边栏。**待办**有三个筛选：待回复、你已发出的回复下面的新动静、已跳过。点一条，原页面在左边打开，这一条的稿留在右边。更换浏览器标签不会把正在改的稿换掉。
4. 回复可以自己写，也可以在**设置**里接上模型，用对话改一版。采用一条对话，那段文字会进入回复草稿。复制草稿，贴到原站，自己发出去。
5. 把刚发出的评论链接贴回来。SideDesk 把它记在这条线索下。每天 8 点（`Asia/Shanghai`，用 `DESK_REFRESH_HOUR` 改小时），以及你按下**立即刷新**时，跑的是同一次检查：监控里的新线索，加上已记录回复上的新动静。

`pnpm dev` 在浏览器标签里打开同一块侧边栏，用来预览。这个预览读不到当前标签。扩展装进 Chrome 之后，面板顶部才会认出左边的页面。

## 现在接到哪一步

| 平台 | 找新帖 | 保存你贴的链接 | 检查你的评论下面 |
| --- | --- | --- | --- |
| Reddit | 关键词搜索。需要 script 应用的密钥。 | 可以。帖子或你自己的评论。 | 可以。同一套密钥。新回复、分数变化，或评论不见了。 |
| YouTube | 还没接。 | 可以先存视频链接。 | 评论拉取还没接。 |
| 哔哩哔哩 | 还没接。 | 可以先存视频链接。 | 评论拉取还没接。 |
| V2EX、知乎、其他 | 还没接。 | 可以手工记下帖子或评论链接。 | 自动检查还没接。 |

Reddit 密钥先空着，也可以记线索、贴评论链接。搜索和 Reddit 自动检查要等密钥填上才跑。模型的 API 密钥存在这台电脑的本地数据库里。

## 环境

- Python 3.12
- pnpm
- Chrome

## 运行

启动 API。没有虚拟环境或依赖时脚本会先装好，没有 `.env` 时会从 `.env.example` 复制一份，然后监听 http://127.0.0.1:8765 ：

```bash
cd backend
./start-backend.sh
```

第一次启动会建好空的「默认」项目。线索和监控从侧边栏里加。

扩展先打一次包：

```bash
cd extension
pnpm install
pnpm build
```

在 Chrome 打开 `chrome://extensions`，打开开发者模式，选择**加载已解压的扩展程序**，选 `extension/dist`。点扩展图标，侧边栏在窗口右边，打开就是待办。后端没开时，侧边栏会提示先跑 `./start-backend.sh`。

开发时预览同一块面板：

```bash
cd extension
pnpm dev
```

打开 http://127.0.0.1:5175 。

## 配置

把仓库根目录的 `.env.example` 复制成 `.env`。`.env` 不存在时，`start-backend.sh` 会做这一步。

Reddit 的搜索和评论检查需要 [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps) 里的一个 script 应用。填上 `REDDIT_CLIENT_ID`、`REDDIT_CLIENT_SECRET` 和 `REDDIT_USERNAME`。

`SEED_PATH` 可以指向一份 Markdown。库里还没有线索时，启动会导入一次。不设就跳过。

## 目录

- `backend/`：本地 API 和数据库
- `extension/`：Chrome 侧边栏
- `data/`：SQLite，不进仓库
- `.env`：密钥，不进仓库
